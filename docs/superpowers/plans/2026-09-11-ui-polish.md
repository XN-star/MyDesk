# MyDesk UI 轻量视觉刷新实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 MyDesk 建立设计 token 体系、精修视觉细节、加入克制微动效，并把四个主题色（teal 默认/indigo/coral/slate）做成设置页可切换选项，三窗口主题同步（修复 quick/widget 不跟随主题的 bug）。

**Architecture:** 全部视觉改动落在单一全局 `src/index.css`（原地精修，token 区置顶）；主题逻辑扩展 `src/lib/theme.ts`（accent class + `useThemeSync` hook）；持久化走 settings 通用 KV 表（无 Rust 改动）；主窗口通过 `theme://changed` 事件向 quick/widget 窗口广播。

**Tech Stack:** Tauri 2 + React 19 + TypeScript + Zustand + 原生 CSS（BEM class）+ Vitest（jsdom）。

**设计文档:** `docs/superpowers/specs/2026-09-11-ui-polish-design.md`

## Global Constraints

- 不拆分 CSS 文件、不引入组件库、不做退场动画、不做列表编排动画、不做间距/字号全量 token。
- 动效时长只允许 `var(--dur-fast)`（120ms）或 `var(--dur)`（180ms）。
- 布局与组件形态不动：不改任何页面结构（App.tsx 仅加 page-fade 包装层）。
- accent class 命名：`accent-teal` / `accent-indigo` / `accent-coral` / `accent-slate`；事件名：`theme://changed`；settings key：`accent`。
- 默认主题色 teal；非法 accent 值一律回退 teal。
- 测试命令 `npm run test`（vitest run），构建命令 `npm run build`，每任务提交一次 git（中文提交信息）。

- [ ] **Step 3: 实现 theme.ts（全文替换）**

```ts
import { useEffect } from 'react';
import { listen } from '@tauri-apps/api/event';
import { api } from './api';

export type ThemeMode = 'system' | 'light' | 'dark';
export type AccentTheme = 'teal' | 'indigo' | 'coral' | 'slate';

export const ACCENTS: AccentTheme[] = ['teal', 'indigo', 'coral', 'slate'];

/** 主窗口 → quick/widget 窗口的主题广播事件名 */
export const THEME_EVENT = 'theme://changed';

export interface ThemePayload {
  theme: ThemeMode;
  accent: AccentTheme;
}

export function resolveDark(mode: ThemeMode, systemDark: boolean): boolean {
  return mode === 'dark' || (mode === 'system' && systemDark);
}

/** 非法/缺省 accent 一律回退 teal（老数据无 accent 键） */
export function normalizeAccent(a: unknown): AccentTheme {
  return ACCENTS.includes(a as AccentTheme) ? (a as AccentTheme) : 'teal';
}

/** 维护 html 上的 dark 与 accent-* class；返回是否深色。 */
export function applyTheme(mode: ThemeMode, accent: AccentTheme = 'teal'): boolean {
  const dark = resolveDark(mode, window.matchMedia('(prefers-color-scheme: dark)').matches);
  const el = document.documentElement;
  el.classList.toggle('dark', dark);
  const acc = normalizeAccent(accent);
  for (const a of ACCENTS) el.classList.toggle(`accent-${a}`, a === acc);
  return dark;
}

/** quick/widget 窗口用：启动读取设置，随后跟随主窗口广播与系统深浅色变化。 */
export function useThemeSync(): void {
  useEffect(() => {
    let mode: ThemeMode = 'system';
    let accent: AccentTheme = 'teal';
    const apply = () => applyTheme(mode, accent);
    api
      .settingsAll()
      .then((all) => {
        mode = (all.theme as ThemeMode) || 'system';
        accent = normalizeAccent(all.accent);
        apply();
      })
      .catch(() => {});
    const un = listen<ThemePayload>(THEME_EVENT, (e) => {
      mode = e.payload.theme;
      accent = normalizeAccent(e.payload.accent);
      apply();
    });
    const mq = window.matchMedia('(prefers-color-scheme: dark)');
    const fn = () => {
      if (mode === 'system') apply();
    };
    mq.addEventListener('change', fn);
    return () => {
      un.then((f) => f());
      mq.removeEventListener('change', fn);
    };
  }, []);
}
```

  }, [theme, accent]);
