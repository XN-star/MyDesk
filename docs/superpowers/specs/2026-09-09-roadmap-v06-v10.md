# MyDesk 版本迭代路线图（v0.6 → v1.0）

日期：2026-09-09
依据：GitHub 同类开源项目调研（Glance 37k★、Dashy 26.4k★、AppFlowy 76.5k★、Joplin 56.3k★、思源笔记 46.2k★、Super Productivity 21.9k★、uhabits 10.2k★、Pomotroid 5.5k★ 等）+ 2025-2026 生产力工具趋势与用户痛点调研。完整调研结论见文末参考。

## 0. 定位不变

本地单机、无账号、SQLite、数据 100% 本地。三大趋势恰好是本项目既有优势：**唯一记录系统、local-first、回顾引擎**（云工具因架构做不彻底，这是单机应用最真实的护城河）。

## 2. 版本规划

### v0.6「焊接版」——低成本高联动，打通既有模块（预计 1 个迭代日）

全部为纯前端或极小后端改动，无新表（除快速面板解析复用现有 parseQuickTask 增强）。

1. **每日笔记**：日历 DayPanel 加「打开/创建当日笔记」按钮，笔记标题约定 `MM月dd日`；数据零改动（notes 表已够用），一个跳转函数。
2. **快速面板语法增强**：parseQuickTask 扩展支持「每天/每周X/每月X号」触发提醒选项、`#标签` 记入任务描述前缀；解析纯函数扩测。
3. **快捷入口增强**：快速面板输入 ` `（空格）后按序号直达前 9 个入口；输入 `/关键词` 展示入口过滤，回车直接 open。
4. **概览周报卡片**：overview.ts 加 `weekReport(tasks, now)` 纯函数（本周完成数/新建数/逾期数、与上周环比），概览页第五张卡片。

验收：日历一键进当日笔记；快速面板一句话建带提醒任务；概览能看本周趋势。

### v0.7「习惯版」——新模块 + 任务闭环第一步（预计 1-2 个迭代日）

1. **习惯追踪模块**（新模块，迁移 v7）：
   - `habits` 表（name/frequency/reminder）+ `habit_logs` 表（habit_id/date/value）
   - 强度评分移植 uhabits 开源算法（纯函数可直译，TDD 友好）
   - 页面：今日打卡列表 + 52 周热力图（GitHub contributions 式）+ streak 统计
   - 复用 reminders 引擎做习惯提醒；概览加「今日习惯」卡片
   - 备份 v7（habits/habit_logs 导出导入兼容）
2. **重复任务**（tasks 表加 `repeat` 列，迁移 v7 同批）：
   - 每日/每周/每月三档（存简单规则字符串，不做完整 RRULE）
   - 完成时由 Rust reminders 轮询顺延生成下一单（或前端完成时生成，实现取简）
   - 日历/概览自动聚合显示

验收：能建「每周三次健身」习惯并打卡看热力图；「每天喝水」任务完成后自动出明天的一单。

### v0.8「专注版」——时间维度闭环（预计 2 个迭代日）

1. **任务计时器**（新表 `time_entries`，迁移 v8）：
   - 看板卡片/抽屉「开始专注」按钮；托盘 tooltip 显示「正在做：X (mm:ss)」
   - 停止写 time_entries；同一时间只允许一个计时
2. **番茄钟**：25/5 分钟档位，可绑定当前计时任务；结束发系统通知；托盘图标进度弧（Pomotroid 有现成 Tauri 2 实现可参考）
3. **今日工时总结**：概览加「今日专注」卡片（总时长/按任务分布），纯 SQL 聚合
4. 备份 v8（time_entries）

验收：对任务一键计时 → 托盘可见 → 番茄结束自动停 → 概览看到今日专注分布。

### v0.9「检索版」——全局搜索与连接（预计 1-2 个迭代日）

1. **全局搜索**（SQLite FTS5 虚拟表，迁移 v9）：
   - tasks/notes/links 三表建 FTS 索引（触发器同步）
   - 快速面板升级：输入即全局搜（任务/笔记/入口分类展示），这也是 Raycast 式体验的核心
2. **笔记 [[双向链接]]**：编辑时 `[[` 触发笔记标题自动补全；详情面板列「引用了它」；数据即文本内 `[[标题]]`，无需新表（FTS 可检索）
3. 备份 v9（FTS 表不导出，导入后重建索引）

验收：快速面板一个框搜全部；笔记互链可跳转可反查。

### v1.0「桌面版」——存在感延伸与打磨（预计 2 个迭代日）

1. **桌面常驻小组件窗口**：Tauri 2 透明/置顶/点击穿透副窗口，默认显示今日任务+下一次提醒+最近笔记，可在设置开关；默认关（可选模块）
2. **设置页增强**：番茄钟时长、习惯提醒时刻、小组件内容选择
3. **工程化补课**：CI（GitHub Actions 跑 vitest+cargo test）、CHANGELOG、安装包自动命名、README 截图
4. **打磨清单**：任务搜索框（看板页内）、笔记字数统计、日历周视图（低优先）、通知点击唤起主窗口（v0.1 遗留）

验收：桌面钉一组小组件；CI 绿；v1.0 发布。

## 3. 排期原则

- 每版本结束都必须是「可打包、可日用」的完整状态（沿用 v0.2–v0.5 的 TDD + 冒烟流程）
- 迁移版本号只在有表结构变更的版本递增（v0.6 无表变更不迁移）
- 每版本完成后按需打包 setup.exe 覆盖安装验证，数据备份惯例保持
- 若中途出现使用痛点反馈，优先级可插队（例如通知相关）
